# Contributing to {a}OS Explorer

Thank you for helping build the shared vocabulary for agentic AI.

## Adding a Product

1. Open a [Product Suggestion issue](https://github.com/vitaminR/aos-explorer/issues/new?template=product-suggestion.md)
2. Include:
   - Product name and vendor
   - Which strata you think it covers (S1-S7)
   - Deployment type (Cloud / Self-hosted / Hybrid)
   - License (Open Source / Commercial / Freemium)
   - Your reasoning for the mapping
3. A maintainer will review, score confidence, and add it to the Explorer

## Correcting a Mapping

If a product is miscategorized:

1. Open a [Mapping Correction issue](https://github.com/vitaminR/aos-explorer/issues/new?template=mapping-correction.md)
2. Explain what's wrong and what it should be
3. Include evidence (docs, changelogs, release notes)

## Taxonomy Changes

Changes to the strata, substrates, or constructs themselves are significant. These go through [Discussions](https://github.com/vitaminR/aos-explorer/discussions) first.

## Code Contributions

- The Explorer is a single HTML file — all CSS and JS are inline
- Zero external dependencies — keep it that way
- Test in Chrome, Firefox, and Safari before submitting
- Follow existing code style (vanilla JS, no framework)

## Code of Conduct

Be respectful, be constructive, be vendor-neutral. The goal is an accurate taxonomy, not product promotion.
