## 🔥 Tier 1 — Add Immediately (high star count + clear stratum fit)

### Google ADK (Agent Development Kit)
- **Stratum:** L4 Orchestration
- **Why hot:** v1.0 stable, 4 language SDKs (Python/TS/Java/Go), native A2A support, visual Agent Designer in GCP console. 17k+ stars and accelerating. The Google-official orchestration answer.
- **Vendor:** Google
- **License:** Open Source (Apache 2.0)
- **Deploy:** Cloud + Local
- **URL:** https://google.github.io/adk-docs/

### Agno
- **Stratum:** L4 Orchestration
- **Why hot:** 38,700+ GitHub stars — biggest framework not in the catalog. Model-agnostic, production-proven, built-in memory + knowledge retrieval + guardrails + 100+ tool integrations. Fills the "standalone orchestrator" gap.
- **Vendor:** Agno (OSS)
- **License:** Open Source
- **Deploy:** Local + Self-hosted
- **URL:** https://github.com/agno-agi/agno

### Smolagents (HuggingFace)
- **Stratum:** L4 Orchestration
- **Why hot:** 25k stars, HuggingFace-backed, ~1000 lines minimal codebase, model-agnostic. Directly competes with CrewAI for lightweight use cases. Strong community pull.
- **Vendor:** HuggingFace
- **License:** Open Source (Apache 2.0)
- **Deploy:** Local
- **URL:** https://github.com/huggingface/smolagents

## 🟠 Tier 2 — Strong Candidates (evaluate stratum fit before adding)

### OpenAI Agents SDK
- **Stratum:** L4 Orchestration
- **Why:** Official OpenAI successor to Swarm. Every major lab now has a framework — this is the OpenAI entry. Should be in Explorer for completeness.
- **Gap:** CrewAI and LangGraph represent the OSS side; this covers the OpenAI-native stack.

### A2A Protocol (Agent2Agent)
- **Stratum:** Cross-cutting / L4
- **Why:** v1.2, 150 orgs in production, now governed by Linux Foundation. Not a product but an interop standard — similar to how MCP is represented. Needs a concept entry + badge on compatible products (CrewAI, Google ADK).
- **Action:** Add as a "protocol" type entry, tag compatible products.

### Warp
- **Stratum:** L3 Execution (Tool Use)
- **Why:** Coding agent platform — local + cloud. Product Hunt trending in "coding agents" category. Bridges terminal use and cloud agent execution.
- **URL:** https://www.producthunt.com/products/warp

### Nova Act (Amazon)
- **Stratum:** L3 Execution / L7 Experience
- **Why:** Amazon's UI-driven web automation agent. Large-scale browser workflows with human oversight + observability hooks. Fills L3 browser-automation gap.

### Codex 3.0 (OpenAI)
- **Stratum:** L3 Execution / L4 Orchestration
- **Why:** End-to-end coding, testing, PRs, CI automation. The OpenAI answer to Devin. Should sit alongside Devin in the catalog.
